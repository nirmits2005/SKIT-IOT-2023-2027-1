## Repository Projects

### 🔐 [Network Intrusion Detection System (NIDS)](./Network-Intrusion-Detection-System/)
A machine learning-powered Network Intrusion Detection System that classifies network traffic into Normal or Malicious categories (detecting DOS, PROBE, R2L, and U2R attacks), deployed with Flask, Docker, and automated Form-3 weekly academic progress reporting.
